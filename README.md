# Photo Slideshow App (Tkinter)

## 📌 Description
A GUI-based Python application that displays a slideshow of images with automatic transitions using Tkinter and PIL.

## 🚀 Features
- Displays images in a window
- Automatic slideshow (changes every 2 seconds)
- Play button to start slideshow
- Image resizing for better display

## 🧠 Concepts Used
- Tkinter (GUI development)
- PIL / Pillow (image processing)
- Event-driven programming
- Working with file paths

## ▶️ How to Run
1. Install required library:
   pip install pillow

2. Run the program:
   python photo-slideshow.py
